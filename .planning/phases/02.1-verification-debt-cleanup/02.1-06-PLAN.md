<objective>
Close WR-07: tags currently accept any string. Add a Zod regex refinement enforcing strict kebab-case (lowercase letters + single hyphens, no digits, no underscores, no leading/trailing hyphens, no double hyphens) so future content-authoring typos fail loudly at build.

Per locked decision (02.1-CONTEXT.md): regex is `^[a-z]+(-[a-z]+)*$` — strict, no digits. Verified against current corpus: every existing tag matches; no digit-bearing tags exist.

Purpose: Prevent silent tag fragmentation (e.g., `bitcoin` and `Bitcoin` becoming separate topic pages, or `self-hosting` vs `self_hosting` not deduping). Build-time fail-loud catches typos before publish.
Output: Regex refinement applied to the `tags` field in `src/content.config.ts` baseSchema; atomic commit; existing content still builds; `astro check` 0/0/0; `astro build` exit 0.
</objective>
