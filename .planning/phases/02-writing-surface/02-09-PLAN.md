**Audit 5 — Internal link count per essay and note page:**
For each essay and note page in dist/, verify ≥2 outbound internal links (links with `href="/"` or `href="/essays/` or `href="/notes/` or `href="/writing` or `href="/about` or `href="/projects` etc. — internal links are those without `http`).

```bash
for page in dist/essays/*/index.html dist/notes/*/index.html; do
  count=$(grep -oE 'href="(/[^"]*)"' "$page" | grep -v "^href=\"/rss" | wc -l)
  if [ "$count" -lt 2 ]; then
    echo "UNDER-LINKED ($count internal links): $page"
  fi
done
```
Expected: no output (all pages have ≥2 internal links). If any page is under-linked: add links to the essay/note source content file (e.g., link to a related note, or link to /writing, or link to /about). The fix lands in `src/content/essays/<slug>.md` or `src/content/notes/<slug>.md` — add meaningful prose links, not forced filler.

Note: Internal nav links (in the nav bar and footer) render on every page via BaseLayout. The count above targets links in the page body proper — EssayLayout and NoteLayout both include at least 1 link via the "Related" block if `related` is populated. If a page has no related entries AND the essay body has fewer than 2 internal links: add at least one link to the essay body (e.g., "See also [my notes on X](/notes/why-astro-over-next)") or add a related slug to the frontmatter.

**Audit 6 — RSS feeds contain at least 1 item:**
```bash
grep -c "<item>" dist/rss.xml; grep -c "<item>" dist/essays/rss.xml; grep -c "<item>" dist/notes/rss.xml
```

Expected: each returns ≥1. If any feed is empty: verify the corresponding collection has published (non-draft) content and that the feed endpoint reads from `getCollection` with `!data.draft`.

```bash

```
Expected: 0. Draft frontmatter should never appear in built HTML — Astro renders the HTML body, not the frontmatter. This check catches a scenario where a template accidentally echoes frontmatter fields as text. If this returns non-zero: inspect the template.
