<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build-time → repo | `npx astro add` and `npm install` execute third-party code at scaffold time. Acceptable; Astro CLI + npm are the trust roots for any Node project. |
| build artifacts → Vercel CDN | The `dist/` output is shipped to Vercel; no user input crosses this boundary. |
| client → static HTML | Visitors load static HTML; no untrusted input is processed by the site. (Phase 1 has no forms, no auth, no API.) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `package.json` deps | mitigate | Pin major versions via caret ranges chosen by `npx astro add`; the CLI selects the current publisher-signed versions. Don't manually edit version strings. |
| T-01-02 | Information Disclosure | `.env` committed by accident | mitigate | `.gitignore` excludes `.env`, `.env.local`, `.env.*.local` (RESEARCH §Security row "Stored secrets"). `.env.example` ships keys only, no values for secrets. |
| T-01-03 | Spoofing | Click-jacking via iframe embed | mitigate | `vercel.json` `X-Frame-Options: DENY` blocks all iframe embedding. |
| T-01-04 | Information Disclosure | Referrer leakage | mitigate | `vercel.json` `Referrer-Policy: strict-origin-when-cross-origin` strips path/query when navigating off-site. |
| T-01-05 | Tampering | MIME-confusion XSS | mitigate | `vercel.json` `X-Content-Type-Options: nosniff` prevents browser MIME guessing. |
| T-01-06 | Tampering | TLS downgrade attacks | mitigate | `vercel.json` HSTS `max-age=63072000; includeSubDomains; preload` (2 years, includes subdomains, preload-list eligible). |
| T-01-07 | Information Disclosure | Browser feature leakage (camera/mic/geo) | mitigate | `vercel.json` `Permissions-Policy: camera=(), microphone=(), geolocation=()` denies all three by default. Phase 1 has no use case for these. |
| T-01-08 | Information Disclosure | CSP not yet enforced | accept | CSP authoring deferred to a follow-up plan that will use Astro 6 native CSP API (RESEARCH Open Question #8).
